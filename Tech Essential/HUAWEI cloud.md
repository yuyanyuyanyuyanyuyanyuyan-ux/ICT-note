

## 一、云计算基础

### 1. 什么是云计算？

**云计算（Cloud Computing）**是一种通过互联网，以按需、可计量的方式获取 IT 资源的计算模式。

用户可以通过网络或编程接口（API）获取所需要的 IT 资源，而不需要自己购买和维护完整的物理基础设施。

主要 IT 资源包括：

- **计算资源（Compute）**
- **存储资源（Storage）**
- **网络资源（Network）**

云计算的核心特点：

> **通过网络获取资源 → 按需使用 → 弹性伸缩 → 按量/按需收费**

传统 IT 与云计算的区别：

```text
传统 IT
购买服务器
    ↓
建设机房
    ↓
部署网络
    ↓
安装操作系统和软件
    ↓
自己维护设备
```

```text
云计算
用户
  ↓
互联网 / API
  ↓
云服务商
  ↓
计算 / 存储 / 网络资源
  ↓
按需使用
```

### 2. 云服务

**云服务（Cloud Service）**是建立在云计算 IT 技术架构之上的、面向用户提供的可计量、按需使用和通常按量计费的 IT 服务。

简单理解：

> **云计算是一种资源和技术提供方式，云服务是用户实际购买和使用的具体服务。**

例如华为云提供的服务可以按照功能划分为：

| 服务类别 | 典型服务 |
|---|---|
| 计算 | 镜像服务、弹性云服务器、弹性伸缩 |
| 存储 | 对象存储、云硬盘、弹性文件服务 |
| 数据库 | 关系型数据库、GaussDB、云原生多模数据库 |
| 网络 | VPC、弹性负载均衡、弹性公网 IP、NAT 网关、对等连接 |
| 安全与管理 | 安全组、统一身份认证、数据加密、云审计 |

## 二、云计算的部署模式

云计算按照部署方式，可以分为：

1. **公有云（Public Cloud）**
2. **私有云（Private Cloud）**
3. **混合云（Hybrid Cloud）**

### 1. 公有云

云服务商建设和维护基础设施，并向多个用户提供云服务。

```text
          云服务商
             │
     ┌───────┼───────┐
     ↓       ↓       ↓
   用户A    用户B    用户C
```

特点：

- 资源由云服务商统一建设和维护
- 多个用户共享云基础设施
- 弹性较强
- 前期建设成本较低

### 2. 私有云

云基础设施主要供一个组织或企业使用。

```text
企业
 ↓
私有云
 ↓
企业内部业务
```

特点：

- 控制能力较强
- 资源和数据隔离程度较高
- 企业通常需要承担更多建设和维护成本

### 3. 混合云

将公有云和私有云结合使用。

```text
        企业私有云
             │
             ↕
           公有云
```

例如：

- 核心数据部署在私有云
- 普通业务部署在公有云
- 业务高峰时利用公有云进行弹性扩展

## 三、云计算的服务模式

云计算按照服务提供层次，可以分为：

1. **IaaS：基础设施即服务**
2. **PaaS：平台即服务**
3. **SaaS：软件即服务**

### 1. IaaS —— 基础设施即服务

**IaaS（Infrastructure as a Service）**

向用户提供基础 IT 基础设施资源，例如：

- 计算
- 存储
- 网络
- 虚拟机

典型理解：

```text
IaaS
 │
 ├── 计算资源
 ├── 存储资源
 ├── 网络资源
 └── 虚拟机
```

用户在 IaaS 上通常还需要管理：

- 操作系统
- 应用程序
- 业务数据

### 2. PaaS —— 平台即服务

**PaaS（Platform as a Service）**

云服务商进一步提供应用开发、部署和运行所需要的平台。

用户可以减少对底层服务器、操作系统等基础设施的管理。

### 3. SaaS —— 软件即服务

**SaaS（Software as a Service）**

云服务商直接向用户提供完整的软件。

用户通常只需要登录并使用软件，而不需要自己部署和维护底层基础设施。

### 4. 三种服务模式对比

| 项目 | IaaS | PaaS | SaaS |
|---|---|---|---|
| 中文 | 基础设施即服务 | 平台即服务 | 软件即服务 |
| 提供内容 | 基础 IT 资源 | 开发/运行平台 | 完整软件 |
| 用户管理程度 | 较高 | 中等 | 较低 |
| 典型理解 | 给你“机器” | 给你“平台” | 直接给你“软件” |

记忆：

> **IaaS 给机器，PaaS 给平台，SaaS 给软件。**

# 四、华为云基础设施

华为云由大量数据中心、计算资源、存储资源、网络资源等组成。

华为云采用 **Region（区域）**、**AZ（可用区）**等地域概念组织云基础设施。

### 1. Region（区域）

Region 是云服务部署的地理区域范围。

不同 Region 通常是相互独立的资源管理和网络范围，**不能简单理解为不同区域之间的资源天然互通**。

跨 Region 部署业务时，需要考虑：

- 网络连接
- 数据同步
- 跨区域访问
- 容灾
- 数据传输成本

### 2. AZ（可用区）

一个 Region 通常可以包含多个相互隔离的可用区。

可以简单理解为：

```text
Region
│
├── AZ1
│
├── AZ2
│
└── AZ3
```

利用多个 AZ 可以提高业务的可靠性和容灾能力。

# 五、华为云核心服务

## 1. 计算服务

核心服务包括：

- **弹性云服务器 ECS**
- **镜像服务**
- **弹性伸缩**

### 1.1 弹性云服务器 ECS

**ECS（Elastic Cloud Server）**可以理解为云上的虚拟服务器。

用户可以根据业务需求选择：

- CPU
- 内存
- 镜像
- 磁盘
- 网络

基本关系：

```text
用户
 ↓
选择镜像
 ↓
创建 ECS
 ↓
获得云服务器
 ↓
部署应用
```

### 1.2 镜像服务

**镜像（Image）**可以理解为创建云服务器时使用的系统模板。

例如：

- Linux 镜像
- Windows Server 镜像

关系：

```text
镜像
 ↓
创建
 ↓
ECS
```

### 1.3 弹性伸缩

**弹性伸缩（Auto Scaling）**可以根据业务负载动态调整计算资源。

例如：

```text
正常业务
 ↓
5 台 ECS

业务访问量增加
 ↓
自动扩展
 ↓
10 台 ECS

业务访问量下降
 ↓
自动缩减
 ↓
5 台 ECS
```

核心思想：

> **业务需要多少资源，就动态提供多少资源。**

# 六、存储服务

华为云常见存储服务包括：

- **对象存储**
- **云硬盘**
- **弹性文件服务**

## 1. 对象存储

对象存储适合保存大量非结构化数据，例如：

- 图片
- 视频
- 音频
- 文档
- 备份文件
- 日志
- 数据集

可以简单理解为：

> **一个可以通过网络访问的海量数据仓库。**

典型应用：

```text
用户
 ↓
上传图片 / 视频
 ↓
对象存储
 ↓
保存数据对象
```

## 2. 云硬盘

云硬盘可以理解为云服务器使用的虚拟硬盘，属于块存储。

例如：

```text
ECS
│
├── 系统盘
│
└── 数据盘
      ↓
    云硬盘
```

适合：

- 操作系统
- 应用程序
- 数据库
- 需要块存储能力的业务

## 3. 弹性文件服务

弹性文件服务提供共享文件系统。

多个云服务器可以访问同一个文件系统。

```text
        文件系统
       /   |   \
      ↓    ↓    ↓
    ECS1 ECS2 ECS3
```

适合：

- 多服务器共享文件
- 企业文件系统
- Web 集群共享数据

## 4. 三种存储方式对比

| 存储类型 | 核心特点 | 典型用途 |
|---|---|---|
| 对象存储 | 以对象形式保存数据 | 图片、视频、备份、数据集 |
| 云硬盘 | 块存储，类似硬盘 | ECS、数据库、应用 |
| 弹性文件服务 | 共享文件系统 | 多服务器共享文件 |

记忆：

> **对象存储存“对象”，云硬盘像“硬盘”，文件服务解决“共享文件”。**

# 七、网络服务

华为云常见核心网络服务包括：

- **虚拟私有云 VPC**
- **弹性负载均衡 ELB**
- **弹性公网 IP EIP**
- **网络 ACL**
- **NAT 网关**
- **对等连接**

## 1. VPC —— 虚拟私有云

**VPC（Virtual Private Cloud）**是云上的虚拟私有网络。

可以理解为：

> **在云平台中划分出来的、属于用户自己的逻辑网络空间。**

例如：

```text
华为云
│
└── VPC
    │
    ├── 子网1
    │    ├── ECS1
    │    └── ECS2
    │
    └── 子网2
         ├── ECS3
         └── ECS4
```

VPC 是构建云上网络环境的重要基础。

## 2. 弹性公网 IP

**EIP（Elastic IP）**是可以分配给云资源使用的公网 IP 地址。

典型关系：

```text
互联网
   ↓
 EIP
   ↓
 云资源
```

主要作用：

> **让云资源能够通过公网进行通信。**

## 3. 弹性负载均衡

**ELB（Elastic Load Balance）**用于将用户请求分发到多个后端服务器。

```text
             用户
              ↓
             ELB
          /   |   \
         ↓    ↓    ↓
       ECS1 ECS2 ECS3
```

主要作用：

- 分发网络流量
- 减轻单台服务器压力
- 提高业务可用性
- 支持业务水平扩展

## 4. 网络 ACL

**网络 ACL（Network Access Control List）**用于控制网络流量访问规则。

例如：

```text
允许：
80 端口
443 端口

拒绝：
其他不需要的访问
```

核心作用：

> **控制网络流量的访问权限。**

## 5. NAT 网关

**NAT（Network Address Translation）网关**用于实现网络地址转换。

典型场景：

```text
             Internet
                 ↑
           NAT Gateway
                 ↑
             私有网络
             /      \
           ECS1    ECS2
```

私有网络中的云服务器可以通过 NAT 网关访问公网，而不一定需要为每台服务器配置公网 IP。

核心记忆：

> **私网资源 → NAT → 公网**

## 6. 对等连接

**VPC Peering（对等连接）**用于连接不同的 VPC，使不同 VPC 中的资源能够进行私网通信。

```text
VPC-A
  │
  │ 对等连接
  │
VPC-B
```

典型用途：

- 不同 VPC 之间通信
- 多业务网络互联
- 跨 VPC 私网访问

# 八、数据库服务

华为云数据库相关服务包括：

- **关系型数据库**
- **GaussDB**
- **云原生多模数据库**

## 1. 关系型数据库

关系型数据库使用表格组织和保存数据。

例如：

| ID | 姓名 | 年龄 |
|---|---|---|
| 1 | 张三 | 20 |
| 2 | 李四 | 21 |

基本组成：

- 表
- 行
- 列
- SQL
- 事务

## 2. GaussDB

**GaussDB** 是华为云数据库产品体系中的重要数据库服务。

可以理解为：

```text
应用
 ↓
数据库服务
 ↓
GaussDB
 ↓
保存和处理业务数据
```

## 3. 云原生多模数据库

多模数据库能够支持不同的数据模型和业务场景。

核心思想：

> **通过云原生架构，为不同类型的数据和业务提供统一的数据库能力。**

# 九、安全与管理服务

核心内容包括：

- **数据加密**
- **统一身份认证 IAM**
- **云审计**
- **安全组**

## 1. 数据加密

通过加密技术保护数据。

基本过程：

```text
明文
 ↓
加密
 ↓
密文
```

只有拥有正确密钥或权限的一方才能解密或使用相关数据。

## 2. 统一身份认证 IAM

**IAM（Identity and Access Management）**主要解决：

> **谁可以访问什么资源，以及可以对资源执行什么操作。**

例如：

```text
管理员
 ↓
可以创建 ECS

普通用户
 ↓
只能查看部分资源
```

IAM 的核心：

> **身份 + 认证 + 授权 + 权限管理**

## 3. 云审计

云审计用于记录云平台上的操作行为。

例如：

```text
管理员
 ↓
删除 ECS
 ↓
云审计记录
 ↓
谁做的？
什么时候做的？
做了什么？
```

可以记忆：

> **IAM 解决“谁能做什么”，云审计解决“谁做了什么”。**

## 4. 安全组

**安全组（Security Group）**是一种虚拟防火墙，用于控制云服务器等资源的网络访问。

例如：

```text
Internet
   ↓
安全组
   ↓
ECS
```

可以通过配置规则控制：

- 入方向流量
- 出方向流量
- IP
- 端口
- 协议
