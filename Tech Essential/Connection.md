# 第四章 云互联

> 本章核心：**VPC → 子网 → NACL / 安全组 → VPC 之间通信 → EIP → NAT → VPN**，重点理解不同网络连接方式分别解决什么问题。

## 一、VPC 与子网

VPC（Virtual Private Cloud，虚拟私有云）是用户在云平台上构建的逻辑隔离的私有网络，可理解为"云上的局域网"。用户无需购买物理交换机、路由器，通过云平台提供的 VPC 服务即可完成私有网络创建、IP 地址规划、子网划分、云资源私网通信与网络隔离，并配合路由表转发流量，配合 NACL、安全组进行网络安全控制。

### 1. VPC 内部路由可达
同一个 VPC 内，不同子网之间通常可以通过私网 IP 通信。但"路由可达"不等于"一定能通信"，还需检查：路由是否正确、NACL 是否允许、安全组是否允许、服务端口是否正常。

### 2. 子网 Subnet
子网是 VPC 内进一步划分的网络分区（VPC 是大园区，子网是园区内的不同区域），用于更精细的 IP 地址规划、网络管理、路由控制、安全控制和业务隔离。VPC 是整个私有网络，Subnet 是 VPC 内部的网络分区。

## 二、NACL：网络访问控制列表

NACL（Network Access Control List）是**子网级防火墙**，控制进入或离开某个子网的网络流量。

### 1. NACL 核心特点
- 子网级控制：作用于整个子网，而非单台服务器
- 一个 NACL 可以关联多个子网；一个子网只能关联一个 NACL
- 可分别配置入方向和出方向规则
- 默认拒绝所有流量，需要通过规则明确允许；配置时要注意返回流量

## 三、安全组 Security Group

安全组是**节点级（云资源级）防火墙**，保护 ECS 等云资源，可配置入方向和出方向规则（如允许 TCP 22 / 80 / 443）。

### 1. NACL 与安全组的区别
NACL 管子网，安全组管节点；NACL 相当于小区大门，安全组相当于每栋楼/每个房间的门禁。

## 四、跨 VPC 通信：VPC 对等连接 Peering

不同 VPC 默认相互隔离。VPC 对等连接（VPC Peering）用于连接两个 VPC，通过**云平台内部网络**实现 VPC 之间的私网互联（不经过公网 Internet）。

### 1. 基本使用流程
创建对等连接 → 添加路由（Peering ≠ 路由自动配置完成，两个方向都需要配置对应路由）→ 检查安全策略（NACL、安全组、服务端口）→ 验证互通。

## 五、弹性公网 IP：EIP

EIP（Elastic IP，弹性公网 IP）是独立的公网 IP 地址，给云资源提供公网身份。适合需要被互联网用户主动访问的资源（如网站服务器）；配置 EIP 的同时还需正确配置安全组、路由和服务端口。

## 六、NAT 网关

NAT（Network Address Translation，网络地址转换）用于私网 IP 与公网 IP 之间的地址转换，让多个私网服务器通过一个 NAT 网关统一访问公网，避免每台 ECS 都拥有独立公网 IP。

### 1. SNAT：私网主动访问公网
SNAT（Source NAT）**修改源地址**，把私网服务器的源 IP 转换为公网 IP。NAT 会记录地址转换关系（私网 IP:随机端口 ↔ 公网 IP:随机端口），互联网返回流量再按记录反向转换回私网 IP。典型场景：ECS 下载软件、更新系统、访问外部 API。

### 2. DNAT：公网主动访问私网
DNAT（Destination NAT）**修改目的地址**，把公网访问入口（公网 IP:端口）映射到私网服务器（私网 IP:端口）。典型场景：发布 Web 服务器、公网用户主动访问私网服务。

### 3. SNAT 与 DNAT 对比

| 对比项 | SNAT | DNAT |
| --- | --- | --- |
| 全称 | Source NAT | Destination NAT |
| 修改对象 | 源地址 | 目的地址 |
| 典型方向 | 内部 → Internet | Internet → 内部 |
| 主要作用 | 私网访问公网 | 公网访问私网 |
| 典型场景 | ECS 下载软件、访问外部 API | 发布 Web 服务器 |
| 记忆 | "我出去" | "别人进来" |

### 4. NAT 网关使用流程
- **SNAT**：创建/购买 NAT 网关 → 指定 VPC/子网等网络范围 → 配置 SNAT 规则 → 指定需要访问公网的私网网段 → 配置公网出口 → ECS 通过 NAT 访问 Internet
- **DNAT**：创建/购买 NAT 网关 → 配置 DNAT → 指定公网访问入口 → 指定内部 ECS → 指定端口映射 → 公网用户访问公网 IP → NAT 转发到 ECS

## 七、EIP 与 NAT 的区别

EIP 是给单台云资源提供独立公网身份（适合网站服务器、对外提供服务的资源）；NAT 是给一批私网资源提供统一的公网访问出口（适合多台 ECS 统一访问公网、不希望每台都配置公网 IP 的场景）。

## 八、VPN：连接云上网络与数据中心

VPN（Virtual Private Network，虚拟专用网络）通常通过公网建立**加密通信隧道**，让企业本地数据中心网络与云上 VPC 网络互联。典型场景：混合云、企业上云（如本地应用访问云上数据库）。

### 1. VPN 与 VPC Peering 的区别
- VPC Peering：云上 **VPC ↔ VPC**，云内部私网互联
- VPN：企业本地数据中心 ↔ 云上 VPC，通过公网建立加密隧道

## 九、连接方式选择与总表

按通信需求判断使用哪种连接方式：
- 同 VPC 内 ECS 通信：VPC 内部路由 + 私网 IP
- 同 VPC 不同子网通信：VPC 内部路由 + 检查 NACL、安全组
- 两个 VPC 之间通信：VPC 对等连接（并配置路由、NACL、安全组）
- 云上 ECS 主动访问 Internet：NAT + SNAT（单台服务器也可用 EIP）
- Internet 用户访问云上服务器：EIP（独立公网入口）或 NAT + DNAT（端口映射）
- 企业数据中心连接云上 VPC：VPN

| 需求 | 推荐方式 | 核心作用 |
| --- | --- | --- |
| VPC 内部资源通信 | VPC 内部路由 | 云内私网通信 |
| 不同子网通信 | VPC 内部路由 | 子网之间通信 |
| 控制子网流量 | NACL | 子网级安全控制 |
| 控制 ECS 流量 | 安全组 | 节点级安全控制 |
| 两个 VPC 互通 | VPC Peering | VPC 私网互联 |
| ECS 独立公网身份 | EIP | 提供公网 IP |
| 多台 ECS 访问 Internet | NAT + SNAT | 统一公网出口 |
| Internet 访问私网 ECS | NAT + DNAT | 公网到私网映射 |
| 数据中心连接云上 VPC | VPN | 本地网络与云网络互联 |

## 十、考试/比赛重点速记

1. VPC = 云上的私有局域网，负责网络隔离、IP 规划、子网划分、云资源私网通信
2. 子网 = VPC 内部进一步划分的网络
3. NACL = 子网级防火墙：一个 NACL 可关联多个子网，一个子网关联一个 NACL
4. 安全组 = 节点级防火墙，控制入方向、出方向
5. Peering = VPC 与 VPC 的私网互联（创建 Peering → 配置路由 → 检查安全策略 → 验证互通）
6. EIP = 独立公网 IP，服务器作为公网服务入口时配置
7. NAT：SNAT 是私网主动出网（源地址转换），DNAT 是公网主动进私网（目的地址转换）
8. VPN = 企业本地网络与云上 VPC 的连接方式（数据中心 ↔ VPN ↔ VPC）

## 十一、一句话记住所有连接方式

同 VPC 靠路由，子网安全看 NACL，服务器安全看安全组；VPC 对 VPC 用 Peering；服务器独立上公网用 EIP；私网统一出公网用 SNAT；公网访问私网用 DNAT；企业数据中心连接云上 VPC 用 VPN。

本章最重要的不是死记服务名称，而是看到网络需求后能够判断"流量从哪里来、到哪里去、经过什么网络设备"。
