# 华为云安全完整笔记（含题目+解析）
## 一、IAM统一身份认证
1. IAM用于账号、权限、身份管理。
2. IAM**不记录资源操作历史日志**。
3. IAM委托：给云服务器/应用授予权限，无需硬编码AK/SK，实现无密钥访问云服务。
4. IAM只管控云平台侧权限；**不管理数据库、服务器内部账号密码**。
5. IAM只管云平台身份，看不到业务内部操作。

### IAM核心概念
- IAM用户：子账号，供人或者应用访问云平台。
- IAM委托：给ECS这类云资源分配权限，不需要AK/SK。
- IAM策略：定义允许、禁止执行哪些操作。

> 典型场景：ECS上业务程序访问OBS，优先使用**IAM委托**，不要把AK/SK写进代码。

## 二、DEW 数据加密服务
1. DEW包含KMS密钥管理、CSMS凭证管理。
2. KMS密钥管理：管理主密钥CMK；**主密钥不会流出DEW服务内部**；支持创建数据密钥、加密数据密钥、解密数据密钥。
3. CSMS凭证管理：集中保管数据库密码、服务器密码等敏感凭证；禁止将密码硬编码写在代码、配置文件中。
4. 配合IAM委托使用，业务运行时动态拉取凭证，搭建无密钥架构，系统本地不保存任何密钥、密码。

## 三、CTS云审计服务
1. CTS记录华为云资源的API操作日志，可以查到操作人、操作时间、操作事件。
2. 原生支持7天内记录过滤查询。
3. 对接LTS云日志服务完成实时日志分析；对接OBS对象存储实现审计日志长期归档保存。
4. CTS服务本身免费；OBS、LTS、DEW配套使用会产生对应费用。
5. 仅记录云平台API操作，**不记录业务应用内部日志**。

## 四、其他相关服务速记
- CES云监控：采集资源指标、配置告警，无法追溯操作人与操作行为。
- OBS对象存储：对象文件存储，可用于长久保存审计日志。
- LTS云日志服务：日志接收、分析处理。

## 五、考试真题（完整题干+选项+答案+解析）
### 题目1
假设你发现一台关键服务器被删除了。以下哪个服务可以帮你确认删除命令是哪个IAM用户发出的( )？
A.云审计服务 CTS
B.云监控服务 CES
C.数据加密服务DEW
D.统一身份验证服务 IAM

**答案：A**

解析：
- A 云审计CTS：记录云资源全部API操作日志，能够定位执行删除操作的IAM用户与操作时间，符合题干需求。
- B CES云监控：负责指标监控、告警，不能记录操作人。
- C DEW数据加密服务：负责密钥与凭证管理，和操作审计无关。
- D IAM统一身份验证：负责账号身份、权限管理，**不保存资源操作历史记录**。

## 六、高频考点速记清单
1. 查询是谁删除ECS实例 → **CTS云审计**
2. ECS内部业务访问云服务，不想硬编码AK/SK → **IAM委托**
3. 数据库密码不写代码，集中安全保管 → **DEW‑CSMS**
4. 安全存放主密钥CMK → **DEW‑KMS**
5. IAM做不到：查询操作日志、管理数据库内部账号密码。
