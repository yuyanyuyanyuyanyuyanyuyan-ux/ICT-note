# 5 云数据库的选择与使用

> 一句话概括：先分清**关系型 / 非关系型（NoSQL）**与 **OLTP / OLAP**，再看华为云 **GaussDB 系列（自研、政企）**与 **RDS 系列（开源、中小企业）**的产品矩阵，最后按业务场景选型。

## 学习目标

- 理解数据库与实例的基本概念。
- 分清关系型数据库（ACID）与非关系型数据库（NoSQL）的差异。
- 理解 OLTP 与 OLAP 的区别与典型场景。
- 掌握华为云数据库服务全景：GaussDB 系列 vs RDS 系列。
- 掌握 **RDS for MySQL** 的功能、特性（跨 AZ 高可用、读写分离、任意时间点恢复）。
- 掌握 **RDS for PostgreSQL** 与 **DDS（兼容 MongoDB）**的特点与适用场景。
- 形成“按场景选型”的思路。

## 正文

### 5.1 数据库基础

- **数据库**：文件的集合，依照某种数据模型将数据组织起来并存放其中，是存储数据的媒介之一（如内存、磁盘）。
- **实例**：内存与后台进程的集合，位于用户和操作系统之间的一层数据管理软件。
- 用户对数据的任何操作（定义、查询、维护、运行控制）都在**数据库实例**下进行；**应用程序只有通过实例才能与数据库打交道**。

### 5.2 关系型 vs 非关系型数据库

| 对比项 | 关系型数据库（SQL / RDBMS） | 非关系型数据库（NoSQL） |
| --- | --- | --- |
| 数据模型 | 二维表（行 × 列），一组表组成数据库 | Key-Value、文档、列族、图等 |
| 事务 | 强调 **ACID**，强一致性，支持细粒度事务与回滚 | 不一定遵循 ACID，多为分布式 |
| 常见产品 | Oracle、SQL Server、DB2、**MySQL**、Microsoft Access | **Redis**、Memcached、Amazon DynamoDB、Azure Cosmos DB 等 |
| 适用 | 事务性要求高、复杂查询 | 海量数据、高并发、灵活 schema、水平扩展 |

**ACID 原则**（关系型数据库的核心）：

- **A**tomicity 原子性：事务要么全做，要么全不做。
- **C**onsistency 一致性：事务前后数据保持一致。
- **I**solation 隔离性：并发事务互不干扰。
- **D**urability 持久性：提交后的数据永久保存。

> NoSQL = **Not Only SQL**，强调 Key-Value 存储和文档数据库的优点，而非单纯反对 RDBMS。

### 5.3 OLTP vs OLAP

| 对比项 | OLTP（联机事务处理） | OLAP（联机分析处理） |
| --- | --- | --- |
| 主要应用 | 传统关系型数据库，日常事务处理（如银行交易） | 数据仓库系统，复杂分析与决策支持 |
| 实时性 | 要求高（实时系统） | 要求不高（常每天更新一次） |
| 数据量 | 查询数据量不大 | 数据量大，多维统计 |
| 查询特点 | 确定性强、并发高、事务完整安全 | 动态查询，以“维”搭建分析平台 |
| 关键指标 | 响应时间（Response Time） | 多维分析灵活性 |

### 5.4 华为云数据库服务全景

华为云同时提供关系型与非关系型数据库服务，按客户类型划分两大系列：

| 系列 | 定位 | 特点 |
| --- | --- | --- |
| **GaussDB 系列** | 华为**自研**，面向**政企**客户 | 企业级分布式关系型数据库；企业级复杂事务混合负载、优异分布式事务、**同城跨 AZ 部署、数据 0 丢失**、支持 **1000+ 扩展**、**PB 级**海量存储；云上高可用、高可靠、高安全、弹性伸缩、一键部署、快速备份恢复、监控告警 |
| **RDS 系列** | 基于**开源**，面向**中小企业**，极致性价比 | 引擎支持 **MySQL / PostgreSQL / SQL Server**；稳定可靠、弹性伸缩、便捷管理、性能监控、多重安全防护、专业管理平台 |

> 每个系列都包含**关系型**与**非关系型**数据库服务。

### 5.5 RDS for MySQL

**定位**：全球最受欢迎的开源数据库之一，搭配 **LAMP（Linux-Apache-MySQL-PHP）**成为 Web 开发的高效方案。即开即用、稳定可靠、安全运行、弹性伸缩、轻松管理、经济实用。

#### 5.5.1 产品架构

- **最小管理单元是实例**，一个实例代表一个独立运行的数据库。
- 实例类型：**单机实例、主备实例**等。

#### 5.5.2 功能

- **弹性伸缩**：
  - 水平伸缩：增删**只读实例**（最多 **5 个**）。
  - 垂直伸缩：实例规格变更、存储空间扩容（**最大 4 TB**）。
- **备份与恢复**：
  - 备份：自动 / 手动、全量 / 增量，备份文件生命周期管理。
  - 恢复：**任意时间点恢复（PITR）**或恢复到某个全量备份时间点，可恢复到新实例 / 原实例；**备份保存周期最高 732 天**。
- **日志管理**：查看慢 SQL 日志、错误日志，下载日志。
- **参数配置**：对数据库引擎参数自定义设置以优化数据库（参数组增删改查、重置、比较、复制）。

#### 5.5.3 三大特性

- **跨 AZ 高可用**：主备集群跨 AZ 部署，实现 **AZ 级别灾备**，保障可靠性。
- **数据库读写分离**：通过**一个读写分离连接地址**自动转发——写请求访问**主实例**，读请求按**读权重**自动访问各实例；单机 / 主备实例最多创建 **5 个只读实例**。
- **任意时间点恢复**：通过备份完成数据恢复；**Binlog** 记录 MySQL 表结构变更与表数据修改的二进制日志，是实现 PITR 的关键。

#### 5.5.4 应用场景

- 其他友商公有云平台用户（应用多采用 MySQL）。
- 有上云政策要求的**政务单位**。
- 快速发展的**初创企业**（MySQL 价格优势友好）。
- **互联网、电商、游戏**类企业（本身大量采用 MySQL）。
- 公司 IT 战略定位为云的客户。

### 5.6 RDS for PostgreSQL

**定位**：典型开源关系型数据库，数据可靠性与完整性表现出色；源自加州大学伯克利分校的 POSTGRES，发展三十余年，是功能最强大的开源数据库之一，业界简称 **PG**。

- **数据库类型**：支持 9.5 / 9.6 / 10.0 / 11 / 12 版本及 **PG 增强版**。
- **安全性**：VPC、子网、安全组、**SSL** 等多重策略。
- **高可用性**：主实例数据复制到备用实例，主故障时可**很短时间切换**到备实例。
- **监控**：计算 / 内存 / 存储容量使用率、I/O 活动、连接数、QPS/TPS、缓冲池、读写活动等。
- **弹性伸缩**：水平增删只读实例（每个集群最多 **5 个**）、垂直规格变更、**一键扩容不中断业务**。
- **日志 / 参数配置**：错误日志、慢 SQL 日志；引擎参数自定义。

**应用场景**：

- **混合运算**：支持 **OLTP + OLAP 混合**场景。
- **多数据模型**：时空、地理、异构、图像、文本检索、时序、流计算、多维等。
- **高可靠**：企业级可靠性、稳定性、数据一致性。
- **去 Oracle**：提供两种方案——**PG 增强版** 或 **PG 社区版 + orafce 插件**。

**两大特性**：

- **高可用**：可靠性优先 / 可用性优先两种模式；AZ 内 / 跨 AZ 高可用；自动 / 手动主备切换；只读实例自动挂到新主库；**故障切换秒级完成**；备库不承担流量以保证 RTO；自研 HA Monitor 模块；VIP 切换、应用透明；可多次主备倒换。
- **任意时间点恢复**：备份周期 **7~732 天**；免费赠送 EVS 同等空间存储、无容量上限；数据可靠性 **11 个 9**；**KMS** 加密、多重防护；OBS 归档存储代替磁带库，实现任意时间点恢复。

### 5.7 DDS（文档数据库服务）

**定义**：**DDS（Document Database Service）完全兼容 MongoDB 协议**，提供安全、高可用、高可靠、弹性伸缩、易用的数据库服务，含一键部署、弹性扩容、容灾、备份、恢复、监控、告警等功能。基本管理单元是**实例**，由**数据库、集合、文档**三部分组成。

| 组成 | 说明 |
| --- | --- |
| 数据库 | 一个实例可建多个数据库，一个数据库可建多个集合 |
| 集合 | MongoDB 文档组，一个集合可包含多个文档 |
| 文档 | 一组键值（key-value）对（BSON），是 MongoDB 中最基本的单元 |

**集群组件（mongos / config / shard）**：

| 组件 | 作用 |
| --- | --- |
| **mongos** | 查询与数据写入的**路由**，实例访问的统一入口；每个实例 2~32 个（用户自定义）；从 config 读配置，将读写请求分发到 shard |
| **config** | 存储实例**配置信息**，由 1 个副本集组成；**用户不能直接连接 config** |
| **shard** | 存储用户**数据**；社区版集群每个实例 2~32 个 shard，每个 shard 由 1 个副本集组成，提供冗余与高可靠；**用户不能直接连接 shard** |

**产品优势**：完全兼容 MongoDB 协议；可视化运维（一键重启 / 备份 / 恢复）；备份与恢复（自动备份保留最长 **732 天**、实时手动备份长期保留，副本集支持实例级 / 库表级时间点恢复）；**支持三种部署架构**。

**三种部署架构**：

| 架构 | 说明 | 适用 |
| --- | --- | --- |
| **集群** | 由路由 mongos、配置 config、分片 shard 组成 | 高并发、大数据量 |
| **副本集** | 主节点 + 备节点 + 隐藏节点，自动搭建三节点副本集，节点间自动同步 | 高可靠生产场景 |
| **单节点** | 作为集群 / 副本集的补充 | 研发、测试等非企业核心数据场景 |

**应用场景**：

- **游戏**：存用户装备、积分等；高峰期用**集群类型**应对高并发；No-Schema 免去频繁改表结构的痛苦。可搭配：模式固定的结构化数据放 **RDS**，模式灵活的业务放 **DDS**，高热数据放 **DCS（Redis）**。
- **IoT**：兼容 MongoDB 的高性能与异步写入；集群可动态扩容 mongos 与 shard，适合高并发写入；二级索引满足动态查询，MapReduce 聚合做多维分析。
- **互联网**：副本集三节点 Replica Set 高可用，节点部署在不同物理服务器，Primary/Secondary 分别提供独立内网地址、配合 Driver 分配读压力；应对 TB 级数据与实时分析需求。

### 5.8 选型思路

| 业务特征 | 推荐服务 |
| --- | --- |
| 传统事务、强一致、结构固定（如 ERP、账务） | 关系型：**RDS for MySQL** / **RDS for PostgreSQL** |
| 政企核心、高可靠、分布式、PB 级 | **GaussDB** 系列 |
| 去 Oracle 迁移 | **RDS for PostgreSQL**（增强版 / orafce） |
| 文档型、schema 灵活、高并发写入（游戏、IoT） | **DDS**（MongoDB 兼容） |
| 缓存 / 高热数据 | **DCS（Redis）** |
| 搜索引擎 | CSS / Elasticsearch 类服务 |
| 数据分析（OLAP） | 数据仓库 / FusionInsight 智能数据湖 |

## 考点 / 易错点

- ⚠️ 数据库 vs 实例：**数据库是文件集合，实例是内存 + 进程**；应用必须通过实例访问数据库。
- ⚠️ 关系型强调 **ACID**，非关系型**不一定遵循 ACID**。
- ⚠️ OLTP = 事务、实时、数据量小；OLAP = 分析、多维、数据量大。别把“维度”用在 OLTP 上。
- ⚠️ 华为云两大系列：**GaussDB 自研→政企**；**RDS 开源→中小企业**。
- ⚠️ RDS for MySQL：只读实例**最多 5 个**、存储扩容**最大 4 TB**、备份保留**最高 732 天**；读写分离靠**只读实例 + 读权重**；PITR 依赖 **Binlog**。
- ⚠️ DDS 三大架构：**集群 / 副本集 / 单节点**；**用户不能直接连接 config 和 shard**，只能连 **mongos**。
- ⚠️ PostgreSQL 高可用切换**秒级完成**、备库不承担流量以保 RTO；去 Oracle 用 **PG 增强版或 orafce**。

## 自测题

1. 简述数据库与实例的区别。
2. 关系型数据库强调的 ACID 分别代表什么？
3. OLTP 与 OLAP 各面向什么场景？衡量 OLTP 的关键性能指标是什么？
4. 华为云数据库的 GaussDB 系列与 RDS 系列分别面向什么客户？
5. DDS 完全兼容哪种协议？其集群由哪三个组件组成？用户能直接连接哪些组件？

**参考答案**

1. 数据库是依某种数据模型组织存放数据的**文件集合**；实例是**内存和后台进程的集合**，位于用户与操作系统之间，应用必须通过实例才能操作数据库。
2. **A**tomicity 原子性、**C**onsistency 一致性、**I**solation 隔离性、**D**urability 持久性。
3. OLTP 面向**日常事务处理**（如银行交易），OLAP 面向**数据仓库的分析与决策支持**；衡量 OLTP 的关键指标是**响应时间（Response Time）**。
4. **GaussDB 系列**为华为**自研**、面向**政企**客户（高可靠、分布式、PB 级）；**RDS 系列**基于**开源**、面向**中小企业**，追求极致性价比。
5. 完全兼容 **MongoDB** 协议；集群由 **mongos（路由）、config（配置）、shard（分片）**组成；用户只能直接连接 **mongos**，**不能直接连接 config 和 shard**。
