# 6 云上安全与管理

> 一句话概括：安全遵循**责任共担模型**——华为云负责“云本身的安全”，客户负责“云内的安全”；围绕**数据 / 计算 / 管理 / 应用 / 网络**五大类，用 **HSS、WAF、DEW、IAM** 等构建纵深防御。

## 学习目标

- 理解云上客户的三大安全诉求与**责任共担模型**。
- 了解华为云**安全合规**能力与**安全服务全景**（五大类）。
- 掌握 **HSS（企业主机安全）** 的定义、工作原理（Agent + 云端防护中心）与优势。
- 掌握 **WAF（Web 应用防火墙）** 的三种部署模式、回源原理与典型场景。
- 掌握 **DEW（数据加密服务）** 四大子服务：KMS、CSMS、KPS、专属加密。
- 掌握 **IAM（统一身份认证）**：账号 / 用户 / 用户组 / 角色 / 策略 / 委托，以及“ECS 访问 OBS 用 IAM 委托而非 AK/SK”的典型场景。

## 正文

### 6.1 责任共担与安全诉求

#### 6.1.1 云上客户对安全的三大诉求

| 诉求 | 含义 |
| --- | --- |
| **业务连续不中断** | 防网络攻击、防黑客入侵、法律遵从、合规 |
| **运维全程可管控** | 配置安全策略、风险识别和处理、操作可审计、可追溯 |
| **数据保密不扩散** | 防外部窃取、内部非授权员工不可见、**云服务商也不可见** |

#### 6.1.2 责任共担模型

安全不是华为云单方面的事，而是**华为云与客户共同承担**：

| 角色 | 负责范围 |
| --- | --- |
| **华为云**（云本身的安全，Security **of** the Cloud） | 数据中心物理安全、基础设施与云平台的安全、云服务自身的安全能力（合规认证、加密能力等） |
| **客户**（云内的安全，Security **in** the Cloud） | 账号与权限管理（IAM）、数据加密与备份、安全组 / 网络 ACL / 防火墙配置、操作系统与应用补丁、业务安全策略 |

> 一句话记忆：**平台的安全归华为云，云上的安全归客户**。

#### 6.1.3 安全合规

- 华为云已通过**全球 50+ 合规认证**，已上线云服务实现 **100% 安全特性覆盖**。
- 常见行业硬性法规：**等保合规、PCI DSS、ISO 27001** 等（云审计 CTS 可助力业务通过此类合规）。
- **HSS 是等保合规的关键项**。

### 6.2 华为云安全服务全景

安全服务种类繁多，本课从**五大类**归纳：**数据安全、计算安全、管理安全、应用安全、网络安全**，每类下都有多个安全云服务，华为云在云安全方面投入甚大。

| 类别 | 代表性服务（举例） |
| --- | --- |
| 数据安全 | **DEW**（KMS / CSMS / KPS / 专属加密） |
| 计算安全 | **HSS**（企业主机安全） |
| 应用安全 | **WAF**（Web 应用防火墙） |
| 管理安全 | **IAM**、CTS（云审计） |
| 网络安全 | Anti-DDoS、VPC 安全组 / 网络 ACL 等 |

### 6.3 HSS 企业主机安全

#### 6.3.1 定义

**企业主机安全（Host Security Service，HSS）** 是提升主机整体安全性的服务，包括**账户破解防护、弱口令检测、恶意程序检测、双因子认证、漏洞管理、网页防篡改**等功能，帮助企业构建服务器安全防护体系，降低服务器面临的主要安全风险。

#### 6.3.2 工作原理（三大组件）

| 组件 | 功能 |
| --- | --- |
| **管理控制台** | 可视化管理平台，集中下发配置、查看区域内主机的防护状态与检测结果 |
| **HSS 云端防护中心** | HSS 的 Server 端；用 AI / 机器学习 / 深度算法分析主机安全风险，集成多种杀毒引擎深度查杀；接收控制台配置与任务并转发给 Agent，接收 Agent 上报信息并生成检测报告 |
| **Agent** | 部署在各主机内部，通过 **HTTPS 和 WSS** 与云端防护中心通信（**默认端口 443**）；每日凌晨定时全量扫描，实时监测安全状态，上报不合规配置、入侵痕迹、软件 / 端口 / 进程列表等 |

**工作流程**：

1. 用户通过控制台下发配置信息与检查任务给 HSS 云端防护中心；
2. 防护中心转发给各主机上的 Agent；
3. Agent 执行检测任务、全量扫描、实时监测，并上报主机信息；
4. 防护中心分析安全风险与异常，以**检测报告**形式呈现到控制台。

#### 6.3.3 产品优势

- **集中管理**：检测与防护一体化管控；支持华为云 ECS / BMS、线下主机、第三方主机统一管理。
- **精准防御**：先进检测技术 + 丰富检测库。
- **全面防护**：**事前预防、事中防御、事后检测**。
- **轻量 Agent**：占用资源极少，不影响主机运行。

#### 6.3.4 应用场景

等保合规、统一安全管理、安全风险评估、账户安全保护（双因子认证）、主动安全防御、黑客入侵检测（应对 APT 等高级威胁）。

### 6.4 WAF Web 应用防火墙

#### 6.4.1 定义

**Web 应用防火墙（Web Application Firewall，WAF）** 通过对 **HTTP(S) 请求**进行检测，识别并阻断 **SQL 注入、跨站脚本攻击（XSS）、网页木马上传、命令 / 代码注入、文件包含、敏感文件访问、第三方应用漏洞攻击、CC 攻击、恶意爬虫扫描、跨站请求伪造（CSRF）** 等攻击，保护 Web 服务安全稳定。

#### 6.4.2 三种部署模式

| 模式 | 防护对象 | 特点 |
| --- | --- | --- |
| **云模式** | 域名 | 弹性扩容能力强，可防护华为云 / 非华为云 / 云下 Web 业务，支持 **IPv6 防护** |
| **独享模式** | 域名或 IP | 资源由用户独享，适合大规模流量攻击防护，**时延低** |
| **ELB 模式** | 域名或 IP | **旁路部署、业务零影响**；WAF 故障时流量直接经 ELB 发给后端，不影响正常业务 |

#### 6.4.3 工作原理（回源）

网站接入 WAF 后，所有访问请求**先流转到 WAF 监控**，恶意流量被检测过滤，正常流量返回源站。WAF 用**回源 IP** 代替客户端向源站发送请求，源站看到的源 IP 都变成 WAF 的回源 IP，从而**隐藏源站**。该过程称为**回源**。

#### 6.4.4 应用场景

- **常规防护**：命令注入、敏感文件访问等常见 Web 安全问题。
- **电商抢购 / 秒杀防护**：灵活设置 **CC 攻击限速策略**，防止业务因并发过高崩溃。
- **0Day 漏洞爆发防范**：第三方框架 / 插件爆出高危漏洞且无法快速修复时，WAF 第一时间升级**预置防护规则**。
- **防数据泄露**：阻断 SQL 注入、网页木马等窃取数据的攻击。
- **防网页篡改**：配置网页防篡改规则。

### 6.5 DEW 数据加密服务

#### 6.5.1 定义

**数据加密服务（Data Encryption Workshop，DEW）** 是综合的云上数据加密服务，提供**专属加密、密钥管理、密钥对管理**等服务，解决数据安全、密钥安全、密钥管理复杂等问题。其**密钥由硬件安全模块（HSM）保护**，并与多个华为云服务集成。

#### 6.5.2 四大子服务

| 子服务 | 全称 | 说明 |
| --- | --- | --- |
| **KMS** | Key Management Service（密钥管理） | 安全、可靠、易用的**密钥托管**服务；密钥由 **HSM** 中的根密钥保护，避免泄露 |
| **CSMS** | Cloud Secret Management Service（凭据管理） | **凭据托管**服务，实现敏感凭据的全生命周期与统一管理，避免程序硬编码 / 明文配置导致泄密 |
| **KPS** | Key Pair Service（密钥对管理） | **SSH 密钥对托管**服务；用 HSM 真随机数生成密钥对，**公钥存于 KPS，私钥由用户下载保存在本地** |
| **专属加密** | Dedicated HSM | 云上数据加密服务，可做加解密、签名、验签、产生并安全存储密钥；提供经**国家密码管理局检测认证**的加密硬件 |

#### 6.5.3 各子服务优势与场景

- **KMS**：
  - 优势：服务集成广泛（可与 **OBS、EVS、IMS** 集成，也可用 KMS API 加密本地数据）；合规遵循（HSM 产生密钥、操作可审计）。
  - 场景：**小数据加解密**（口令、证书、电话号码等，**不大于 4KB**）；**大量数据加解密**（照片、视频、数据库文件等，采用**信封加密**，无需传输大量数据）。
- **CSMS**：凭据加密保护（集成 KMS、TLS 传输）、安全检索（用 API 调用替换硬编码凭据）、**凭据双重轮换**（多版本 + 加密密钥自动轮换）、集中管控（与 IAM、CTS 集成）。
- **KPS**：登录安全增强（免密码登录 Linux 云服务器）、合规遵循；场景：登录 Linux ECS（密钥对方式）或获取 **Windows ECS 登录密码**。
- **专属加密**：云上使用、弹性扩容、安全管理（设备管理与内容管理**权限分离**，Dedicated HSM 只负责监控设备）、权限认证（口令 / 数字证书）、可靠性（国密或 **FIPS 140-2 第 3 级**硬件加密机）、安全合规、应用广泛；场景：敏感数据加密、金融支付加密、电子票据加密。

### 6.6 IAM 统一身份认证

#### 6.6.1 定义

**统一身份认证（Identity and Access Management，IAM）** 是华为云提供权限管理的**基础服务**，帮助用户安全地控制华为云服务和资源的访问权限。**IAM 无需付费**即可使用，用户只需为账号中的资源付费。

#### 6.6.2 核心概念

| 概念 | 说明 |
| --- | --- |
| **账号** | 注册华为云后系统自动创建；是资源的归属与使用计费的**主体**，拥有完全控制权限，可访问所有云服务；不能在 IAM 中修改 / 删除 |
| **IAM 用户** | 由管理员在 IAM 中创建，用户名 + 密码登录；**不拥有资源、不独立计费**，权限和资源由所属账号统一控制与付费 |
| **用户组** | 用户的集合，通过用户组实现批量授权；用户加入多个用户组即获得多组权限的**全集**；`admin` 为缺省用户组，拥有所有云服务权限 |
| **角色** | IAM 最初的**粗粒度**授权机制（以服务为粒度），可能需要一并授予依赖角色 |
| **策略** | IAM 最新的**细粒度**授权能力，可精确到具体服务的操作、资源与请求条件，满足**权限最小化** |
| **委托** | 将本账号资源的操作权限委托给其他账号；**只能对账号委托，不能对 IAM 用户委托** |

#### 6.6.3 三大产品优势

1. **精细访问控制**：账号拥有完全权限；用 IAM 用户 + 授权实现多用户协同，**避免分享账号密码**。
2. **跨账号资源操作与授权**：用 **委托** 功能把资源委托给其他账号（如代运维公司），委托关系变化时可随时修改或撤销。
3. **使用企业已有账号登录**：用 **身份提供商** 功能建立企业与华为云的信任关系，通过**联合认证**让员工用企业已有账号直接登录，实现**单点登录（SSO）**。

#### 6.6.4 策略（Policy）结构与规则

- 策略结构：`Version`（版本号，如 `1.1`）+ `Statement`（授权语句，可多条）。
- 语句要素：**Effect**（Allow / Deny）、**Action**（授权项，格式“服务名:资源类型:操作”）、**Condition**（条件）、**Resource**（资源）。
- **Deny 优先**：同一 Action 同时有 Allow 和 Deny 时，遵循 **Deny 优先**。
- 常用全局条件键：`g:UserName`、`g:DomainName`、`g:MFAPresent`、`g:SourceIp`、`g:SourceVpc` 等。

#### 6.6.5 典型场景：ECS 访问 OBS 用 IAM 委托，而不是 AK/SK

**推荐做法**：给 ECS 绑定**委托 / 临时凭证**，由 IAM 动态颁发**临时安全凭证**，云服务器凭此访问 OBS。

**为什么不用永久 AK/SK**：

- 永久 AK/SK 一旦**硬编码在代码 / 配置文件中**，极易因泄露导致数据被窃取，且难以轮换。
- 临时 AK/SK + SecurityToken **有效期 15 分钟 ~ 24 小时**，过期需重新获取，**遵循权限最小化原则**，安全得多；若未使用 SecurityToken 会返回 **403** 错误。
- 委托方式**无需在服务器上存放任何长期密钥**，权限可随时修改 / 撤销，符合最小权限与审计要求。

> 记忆：**云上资源互访优先用 IAM 委托 + 临时凭证，避免把永久 AK/SK 写进代码**。

## 考点 / 易错点

- ⚠️ **责任共担**别记反：**华为云 = 云平台自身安全；客户 = 云上业务 / 数据 / 权限 / 配置安全**。
- ⚠️ HSS 三组件：**控制台、云端防护中心（Server 端）、Agent**；Agent 默认端口 **443**，每日**凌晨**全量扫描。
- ⚠️ WAF 三种模式：**云模式（域名）/ 独享模式（域名或 IP）/ ELB 模式（旁路、零影响）**；核心概念是**回源**与**隐藏源站**。
- ⚠️ DEW 四件套区分：**KMS 管密钥、CSMS 管凭据、KPS 管 SSH 密钥对、专属加密管硬件加密机**；KMS 小数据 ≤ **4KB**，大数据用**信封加密**。
- ⚠️ IAM：**委托只能委托给“账号”，不能委托给 IAM 用户**；IAM 用户**不拥有资源、不独立计费**；策略遵循 **Deny 优先**。
- ⚠️ 典型场景：**ECS 访问 OBS 用 IAM 委托 / 临时凭证，而非把永久 AK/SK 硬编码**；临时 AK/SK 有效期 15 分钟~24 小时，缺 SecurityToken 报 **403**。

## 自测题

1. 简述华为云“责任共担模型”中，华为云与客户分别负责什么？
2. HSS 由哪三个组件构成？Agent 与云端防护中心通过什么协议通信、默认端口是多少？
3. WAF 有哪三种部署模式？其中哪种是旁路部署且对业务零影响？“回源”指什么？
4. DEW 包含哪四个子服务？KMS 处理“小数据加解密”的上限是多少字节？大数据用哪种加密方式？
5. 为什么推荐 ECS 访问 OBS 时使用 IAM 委托 / 临时凭证，而不是永久 AK/SK？

**参考答案**

1. **华为云**负责“云本身的安全”（数据中心、基础设施、云平台及云服务自身的安全能力）；**客户**负责“云内的安全”（账号权限、数据加密与备份、安全组 / 网络 ACL 配置、系统与应用补丁、业务安全策略）。
2. **管理控制台、HSS 云端防护中心、Agent**；Agent 通过 **HTTPS 和 WSS** 协议与云端防护中心通信，**默认端口 443**。
3. **云模式、独享模式、ELB 模式**；**ELB 模式**是旁路部署、业务零影响。“回源”指 WAF 用**回源 IP 代替客户端**向源站服务器发送请求，使源站看到的源 IP 变为 WAF 回源 IP，从而**隐藏源站**。
4. **KMS（密钥管理）、CSMS（凭据管理）、KPS（密钥对管理）、专属加密（Dedicated HSM）**；KMS 小数据加解密**不大于 4KB**；大数据采用**信封加密**。
5. 永久 AK/SK 一旦**硬编码 / 明文配置**极易泄露且难轮换；**临时凭证有效期仅 15 分钟~24 小时、遵循权限最小化原则**，委托方式无需在服务器存放长期密钥、权限可随时修改 / 撤销，更安全、更易审计。
