# 2 云中的计算

> 一句话概括：**计算是云上的"发动机"——华为云用 ECS（弹性云服务器）替代传统服务器，用 BMS 补齐物理机性能，用 IMS 解决系统交付，用 AS 解决弹性，用 CCE 走向容器化。**

## 学习目标

- 掌握 **弹性云服务器 ECS** 的定义、架构、优势、购买流程、访问方式和应用场景。
- 理解 **裸金属服务器 BMS** 的定位，会区分 BMS / ECS / 物理机。
- 掌握 **镜像服务 IMS** 的分类、优势与常见使用（创建、共享、加密、复制、导出）。
- 掌握 **弹性伸缩 AS** 的核心概念（伸缩组/配置/策略/活动/冷却时间）与创建流程。
- 了解 **云容器引擎 CCE** 的核心概念、架构、优势与配置流程。
- 认识其他计算服务：云手机 CPH、专属主机 DeH、云耀云服务器 HECS。

## 2.0 计算类云服务概览

本章的计算服务包括：**弹性云服务器（ECS）、裸金属服务器（BMS）、弹性伸缩（AS）、GPU 加速云服务器、云容器引擎（CCE）、云手机（CPH）、镜像服务（IMS）、专属主机（DeH）** 等。其中 ECS、BMS、IMS、AS、CCE 为重点。

## 3.1 弹性云服务器 ECS

### 3.1.1 定义

> 弹性云服务器（Elastic Cloud Server，**ECS**）是由 **CPU、内存、操作系统、云硬盘**组成的基础计算组件。创建成功后，用户可以像使用本地 PC 或物理服务器一样在云上使用它。

### 3.1.2 产品架构

ECS 是一款**横跨多类服务的综合性产品**，通过与其它服务组合实现完整能力：

- 可在**不同可用区**部署，部分 AZ 故障不影响同 Region 其它 AZ；
- 通过 **VPC（虚拟私有云）**建立专属网络环境，设置子网、安全组，通过**弹性公网 IP**实现外网连接（需带宽支持）；
- 通过 **IMS 镜像服务**部署操作系统，也可用私有镜像批量创建 ECS；
- 通过 **EVS 云硬盘**实现数据存储，通过云硬盘备份实现备份与恢复；
- 通过**云监控**观察资源使用情况；
- 通过**云备份**提供对云硬盘和 ECS 的备份保护（基于快照技术），并支持用备份数据恢复。

### 3.1.3 优势（四点）

| 优势 | 说明 |
| --- | --- |
| 稳定可靠 | 丰富云硬盘类型；分布式架构、高数据可靠性与高 I/O 吞吐；支持自动备份与指定时间点备份/恢复 |
| 安全保障 | WAF、漏洞扫描等多维防护；安全评估与配置检查；基于可定制白名单的进程管理服务 |
| 软硬结合 | 搭载专业硬件、深度虚拟化优化；随时从资源池获取并独享资源，按业务弹性扩展 |
| 弹性伸缩 | 结合 **AS** 放入伸缩组，随监控数据动态增减实例；支持定时及周期性伸缩策略 |

### 3.1.4 购买流程

1. **准备阶段**：华为云账号 + 充值。
2. **基础配置**：
   - 计费模式：按需、包周期（按月/按年）、竞价共 3 种；
   - 区域和可用区：**不同区域云服务产品之间内网互不相通**，建议就近选择；
   - CPU 架构：**X86 采用复杂指令集 CISC；鲲鹏采用精简指令集 RISC**；
   - 规格 / 镜像。
3. **网络配置**：子网、安全组、扩展网卡（可选）。
   - 子网：管理 ECS 网络平面，提供 IP 地址管理与 DNS；可用 DHCP 随机分配或手工指定 IP；
   - 安全组：逻辑分组，为具有相同安全保护需求且相互信任的 ECS 提供访问策略。
4. **高级配置**：云服务器名称、登录凭证（密钥对 / 密码）、云备份、云服务器组（反亲和，尽量分散在不同主机）、高级选项。
5. **配置确认**：确认后同意用户协议并购买。

### 3.1.5 访问方式

- **API 方式**：集成到企业第三方系统做二次开发；
- **控制台方式**：登录华为云官网 → 管理控制台 → 弹性云服务器 → 远程登录；
- **SDK 方式**：SDK 对接管理。

具体登录方式还与操作系统有关。

**登录 Windows ECS**（用户名 `Administrator`，仅运行中可登录）：

| 方式 | 是否需绑定 EIP | 端口 |
| --- | --- | --- |
| 管理控制台远程登录（VNC 方式） | 否 | — |
| 管理控制台提供的 RDP 文件登录（推荐） | 是 | 3389 |
| 远程桌面连接（MSTSC） | 是 | 3389 |
| 移动设备（Microsoft Remote Desktop 等） | 是 | 3389 |
| Mac OS（Microsoft Remote Desktop for Mac） | 是 | 3389 |

> 密钥方式鉴权的 ECS，需先通过控制台的"获取密码"功能把私钥解析为密码。

**登录 Linux ECS**（用户名 `root`，仅运行中可登录）：

| 方式 | 是否需绑定 EIP | 端口 |
| --- | --- | --- |
| 管理控制台远程登录（VNC 方式） | 否 | — |
| Windows 设备 SSH 密码方式 | 是 | 22 |
| 移动设备（Termius、JuiceSSH 等 SSH 客户端） | 是 | 22 |

### 3.1.6 常用操作

**重装 / 切换操作系统**注意事项：

- 重装后 **IP 地址和 MAC 地址不变**；
- 重装会**清除系统盘数据**（含系统分区与所有其它分区），需先备份；**不影响数据盘数据**；
- 重装后几分钟内在注入密码/密钥，期间勿执行其它操作；
- Windows 若重装时设了新密码，本地 RDP 文件失效，需重新下载。

**变更规格**（升/降 vCPU、内存）注意事项：

- 不能选择已售罄的 CPU/内存资源；
- 规格变小会影响性能；部分类型暂不支持变更；
- 云硬盘"正在扩容"时不支持变更；
- Windows ECS 变更时需修改 SAN 策略避免磁盘脱机；
- 包年/包月：需补齐差价（多退少补），重启生效；按需计费：不需补齐差额。

**重置密码**前提条件：

- 密码丢失/过期前已安装密码重置插件（公共镜像默认已装一键重置密码插件）；
- 勿删除 `CloudResetPwdAgent`、`CloudResetPwdUpdateAgent` 进程；
- SUSE 11 SP4 镜像内存需 ≥ 4GB；
- VPC 网络 DHCP 不能禁用，且网络正常通行。

### 3.1.7 应用场景

| 场景 | 推荐规格 | 说明 |
| --- | --- | --- |
| 网站应用 | 通用型 ECS + ELB + VPC | 部署网站开发测试环境、小型数据库或 Web 服务器 |
| 企业电商 | 内存优化型 + 超高 IO 云硬盘 + 合适带宽 | 内在要求内存高、数据量大、访问量大、快速交换处理 |
| 图形渲染 | GPU 图形加速型（G1，基于 NVIDIA Tesla M60） | 支持 DirectX/OpenGL，最大显存 1GiB、分辨率 4096×2160 |
| 数据分析 | 磁盘增强型（自带本地盘） | 高存储 IOPS 与读写带宽，适合 Hadoop 等 |
| 高性能计算 | 高性能计算型 | 每个 vCPU 对应一个至强可扩展处理器核心的超线程，适合科研行业 |

## 3.2 裸金属服务器 BMS

### 3.2.1 定义

> 裸金属服务器（Bare Metal Server，**BMS**）是一款兼具**虚拟机弹性**和**物理机性能**的计算类服务，为用户提供专属的云上物理服务器。

BMS 与传统物理机本质都是物理设备，最大区别：**BMS 能把物理机接入云平台，实现自动化配置、自服务化购买**；传统物理机只能人工手动配置、线下采购。即：BMS 让物理机具备自动发放、自动运维、VPC 互联、支撑对接共享存储等"云能力"。

### 3.2.2 产品架构

与 VPC、EIP、IMS、EVS、云监控、云备份等服务组合，实现计算、存储、网络、镜像安装等功能（能力范围与 ECS 基本一致）。

### 3.2.3 优势

- **安全可靠**：用户专属计算资源，支持 VPC、安全组隔离；主机安全组件集成；支持云磁盘作系统盘/数据盘与硬盘备份恢复；可对接专属存储。
- **性能卓越**：无虚拟化开销和性能损耗，100% 释放算力；结合擎天软硬协同架构支持高带宽、低时延。
- **敏捷的部署效率**：分钟级资源发放，统一 Console + 开放 API/SDK 支持自助式生命周期管理。
- **云服务快速集成**：基于统一 VPC 模型，加速数据库、大数据、容器、HPC、AI 等业务云化。

### 3.2.4 BMS、ECS 与物理机对比

| 维度 | 物理机 | 虚拟机（ECS） | 裸金属（BMS） |
| --- | --- | --- | --- |
| 性能 | 无虚拟化损耗，强 | 有虚拟化损耗 | 无损耗，物理机级性能 |
| 灵活性 | 差（周期长、运维复杂、架构僵化） | 好（弹性） | 好（在线交付、自动运维） |
| 资源占用 | 独享 | 多用户共享物理资源 | 用户独享物理资源 |
| 隔离性/安全性 | 高 | 相对低 | 物理机级隔离 |

> 结论：关键数据库、高性能计算、对 IO 性能要求极高、对核心数据要求高度掌控/安全隔离的业务 → 选 **BMS**。

### 3.2.5 创建流程

创建方式：创建裸金属服务器 / 创建快速发放型裸金属服务器 / 创建专属裸金属服务器 / 通过私有镜像创建 BMS。

- **步骤 1 基础配置**：计费模式（仅包周期：按月、按年）、区域/可用区、规格/镜像。
- **步骤 2 网络配置**：首次使用时系统自动创建默认 VPC（默认地址范围 **192.168.1.0/24**，子网网关 192.168.1.1，开启 DHCP）。创建 BMS 时**仅支持选择一个安全组**，创建成功后可关联多个安全组。

BMS 支持的 **5 种网络类型**（相互隔离不互通）：

| 网络类型 | 说明 |
| --- | --- |
| 虚拟私有云 VPC | 隔离、自主配置管理的虚拟网络环境，可定义安全组、VPN、IP 地址段、带宽等 |
| 高速网络 | BMS 内部网络，同 AZ 内 BMS 间高带宽，最大 **10Gbps** |
| 增强高速网络 | 软硬件优化升级，带宽提升至 **10GE 及以上**；自定义网络平面最多 4K 子网；支持 BMS 虚拟化访问外网 |
| 自定义 VLAN 网络 | 物理上采用 **QinQ** 实现隔离，网卡成对出现可配 bond 高可用；当前不支持跨 AZ 互通 |
| IB 网络 | 低延迟高带宽，用于 HPC；采用 **100G Mellanox IB 网卡**，通过专用 IB 交换机和 UFM 管理；通过 **Partition Key** 实现隔离 |

- **步骤 3 高级配置**：名称、登录凭证（密钥对 Key Pair / 密码）。Linux BMS 建议用密钥对，**私钥只能下载一次**，请妥善保管。

### 3.2.6 重装系统

- 重装需**停止 BMS，会中断业务**；
- 会清除系统盘数据（含所有分区），需先备份；
- 重装过程中禁止关机/重启，否则可能失败；
- 重装后个性化设置（DNS、主机名等）将被重置，需重新配置。

### 3.2.7 应用场景

- **证券金融行业**：合规性与数据安全要求苛刻，资源独享、数据隔离、可监管可追溯；
- **高性能计算**：超算中心、基因测序等；
- **核心数据库**：不能部署在虚拟机上，须资源专享、网络隔离、性能有保障；
- **移动应用**：基于鲲鹏系列 BMS 打造一站式方案。

## 3.3 镜像服务 IMS

### 3.3.1 定义

> 镜像服务（Image Management Service，**IMS**）提供**镜像的生命周期管理能力**。用户可灵活使用公共镜像、私有镜像或共享镜像申请 ECS / BMS；也能通过已有的云服务器或外部镜像文件创建私有镜像，实现业务上云或云上迁移。

镜像 = 包含软件及必要配置的服务器或磁盘**模版**，包含操作系统或业务数据，还可包含应用软件（如数据库软件）和私有软件。

### 3.3.2 分类

| 类型 | 说明 |
| --- | --- |
| **公共镜像** | 厂商默认提供，所有用户可见；含标准 OS 镜像。官方支持：Windows、CentOS、Debian、openSUSE、Fedora、Ubuntu、EulerOS、CoreOS |
| **私有镜像** | 用户自己创建，仅个人可见。分：**系统盘镜像**（OS + 应用软件）、**数据盘镜像**（仅业务数据）、**整机镜像**（OS + 应用软件 + 业务数据） |
| **共享镜像** | 其他用户共享的私有镜像 |
| **市场镜像** | 服务商提供的优质第三方镜像，经华为云严格测试审核，无需配置一键部署 |

### 3.3.3 优势

| 优势 | 说明 |
| --- | --- |
| 便捷 | 各类镜像均可批量创建云服务器；支持通过 ECS/BMS/外部镜像文件创建；可共享、复制、导出，实现跨账号/跨区域/跨云平台迁移 |
| 安全 | 公共镜像均正版授权、严格测试；镜像文件用 **OBS 多份冗余存储**；可用 **KMS 信封加密**私有镜像 |
| 灵活 | 控制台或 API 均能完成生命周期管理 |
| 统一 | 提供统一镜像自助管理平台，实现应用系统统一部署与升级，保证环境一致 |

### 3.3.4 创建（以通过 ECS 创建 Windows 系统盘镜像为例）

常见创建方式两大类：**通过云服务器创建** 和 **通过外部镜像文件创建**。其他方式：通过 ISO 文件创建 Windows/Linux 系统盘镜像、通过云备份创建整机镜像、通过 BMS 创建 BMS 系统盘镜像。

流程要点：

1. 准备一台 Windows ECS，检查网卡属性是否为 **DHCP** 方式（若是静态 IP，需登录修改为 DHCP）；
2. 建议安装 **Cloud-init / Cloudbase-init** 工具（使新 ECS 可自定义配置）；确保镜像安装了 **PV driver 和 UVP VMTools**（同时支持 XEN 和 KVM 虚拟化）；
3. 在"镜像服务"页 → 创建私有镜像 → 选择"系统盘镜像" → 源选"云服务器"。

### 3.3.5 使用

- **修改镜像属性**：仅"私有镜像"且状态为"正常"的可修改；可改名称、描述、最小/最大内存、是否支持网卡多队列、SRIOV 驱动等。
  - 网卡多队列：把网卡中断分散给不同 CPU 处理，实现负载均衡；SRIOV 驱动：提高网络处理性能。
- **删除镜像**：删除后无法找回，不能再用于创建云服务器/云硬盘；已用它创建的 ECS 仍可正常使用（但无法重装 OS、不能创建相同配置）。删除复制镜像的源镜像不影响复制后的镜像，反之亦然。
- **共享镜像**：可共享给其他华为云账号使用。
- **加密镜像**：采用 **KMS 信封加密**。注意：加密镜像**不能共享、不能发布到应用超市**；用加密镜像创建的 ECS，系统盘只能是加密状态，且磁盘密钥与镜像密钥一致。
- **区域内复制镜像**：可实现加密/非加密转换，或使镜像具备高级特性（如快速发放）。
- **导出镜像**：将"可用"状态的私有镜像导出到 **OBS 桶**并指定格式；导出占用 OBS 空间并按实际大小收费。

### 3.3.6 应用场景

- **服务器上云或云上迁移**：支持 vhd、vmdk、qcow2、raw 等格式导入；
- **部署特定软件环境**：用共享镜像或市场镜像快速搭建；
- **批量部署软件环境**：打包制作私有镜像后批量创建；
- **服务器运行环境备份**：制作镜像备份，故障时可恢复。

## 3.4 弹性伸缩服务 AS

### 3.4.1 定义

> 弹性伸缩（Auto Scaling，**AS**）根据用户业务需求，通过设置**伸缩规则**自动增加/缩减业务资源。业务增长时自动增加 ECS 实例或带宽，业务下降时自动缩减，以节约成本。

### 3.4.2 相关概念

| 概念 | 含义 |
| --- | --- |
| 伸缩组 | 具有相同应用场景的实例的集合，是启停伸缩策略和进行伸缩活动的基本单位 |
| 伸缩配置 | 伸缩组内实例（ECS）的**模板**，定义待添加实例的规格数据（类型、vCPU、内存、镜像、磁盘、登录方式等） |
| 伸缩策略 | 触发伸缩活动的方式，规定触发条件及执行的操作 |
| 伸缩活动 | 伸缩组中增加或减少实例的过程 |
| 冷却时间 | 避免告警策略频繁触发而设置；每次伸缩活动完成后开始计算；冷却时间内**拒绝告警策略**触发的伸缩活动，其他类型（定时/周期）不受限但会重新开始计算冷却时间（单位：秒） |
| 伸缩带宽 | 自动调整带宽资源；**仅支持按需购买的 EIP 带宽和共享带宽**，不支持包年包月带宽 |

> ⚠️ 冷却时间例子：冷却时间 300 秒；定时策略 10:32 触发、10:30 告警触发的伸缩活动结束 → 10:30–10:35 拒绝新告警触发的伸缩活动，但不拒绝 10:32 的定时策略；若 10:36 定时策略的伸缩活动结束，则冷却时间为 10:36–10:41。

### 3.4.3 产品架构

通过**伸缩控制**实现 ECS 实例伸缩与带宽伸缩：

- **伸缩控制**：配置策略设置指标阈值/伸缩时间，通过云监控监控指标是否达阈值，通过定时调度实现；
- **配置策略**：告警策略 / 定时策略 / 周期策略；
  - 告警策略可配 CPU、内存、磁盘、入网流量等监控指标；
  - 定时策略通过配置触发时间；
  - 周期策略通过配置重复周期、触发时间、生效时间。

### 3.4.4 优势（四点）

- **自动调整资源**：按需自动增减实例数量与带宽；
- **加强成本管理**：按需使用，节省资源与人工调整损耗；
- **提高可用性**：始终拥有合适容量；结合负载均衡后自动为新实例绑定监听器，流量自动分发；
- **提高容错能力**：检测实例运行状况，启用新实例替换运行不佳的实例。

### 3.4.5 创建流程

1. **创建伸缩配置**：① 使用已有 ECS 快速创建（vCPU、内存、镜像、磁盘、类型默认与所选用 ECS 一致）；② 使用新模板创建（按需求自定义规格参数）。
2. **创建伸缩组**：配置多可用区扩展策略、最大/期望/最小实例数、实例移除策略、健康检查等。
   - 多可用区扩展策略：选两个及以上 AZ 时才需配置；
   - 期望实例数介于最小与最大实例数之间；
   - 实例移除策略：若存在不属于当前配置可用区的实例，会优先移除。
3. **创建伸缩策略**：配置策略类型和冷却时间。业务负载难以预测时选**告警策略**，系统按实时监控数据（如 CPU 使用率）触发。

### 3.4.6 应用场景

- 访问流量较大的**论坛网站**（负载难预测，按 CPU/内存使用率动态调整）；
- **电商网站**促销活动时定时增加实例数量和带宽；
- **视频直播**网站每天固定时段（如 14:00~16:00）增加实例和带宽。

## 3.5 云容器引擎 CCE

### 3.5.1 定义

> 云容器引擎（Cloud Container Engine，**CCE**）提供高度可扩展的、高性能的**企业级 Kubernetes 集群**，支持运行 Docker 容器。用户可在华为云上轻松部署、管理和扩展容器化应用。

### 3.5.2 相关概念

| 概念 | 含义 |
| --- | --- |
| 集群（Cluster） | 容器运行所需的云资源组合，关联若干云服务器节点、负载均衡等；为容器运行提供计算资源池 |
| 节点（Node） | 对应一台服务器（VM 或物理机），容器应用运行其上；运行 Agent（kubelet）管理容器实例；数量可伸缩 |
| 节点池（NodePool） | 集群中具有相同配置的一组节点 |
| 实例（Pod） | Kubernetes 部署应用或服务的**最小基本单位**；封装多个应用容器、存储资源、独立网络 IP 及管理策略 |
| 容器（Container） | 通过 Docker 镜像创建的运行实例；实质是进程，运行于独立命名空间 |
| 工作负载 | Kubernetes 上运行的应用程序，是对一组 Pod 的抽象模型；含 Deployment、Statefulset、Daemonset、Job、CronJob 等 |
| 镜像（Image） | Docker 镜像，容器应用打包的标准格式，用于创建容器；**不包含动态数据，构建后内容不可改变** |
| 七层负载均衡（Ingress） | 为进入集群的请求提供路由规则的集合（URL、负载均衡、SSL 终止、HTTP 路由等） |
| 镜像仓库 | 存放 Docker 镜像 |

> 镜像 vs 容器：镜像是静态定义（类），容器是镜像运行时的实体（实例）。

### 3.5.3 产品架构

CCE 深度整合华为云的计算（ECS/BMS）、网络（VPC/EIP/ELB）、存储（EVS/OBS/SFS）等服务，支持 GPU/NPU/ARM/FPGA 等异构计算架构，支持多 AZ、多 Region 容灾构建高可用 K8s 集群。既可图形化控制台操作，也支持 K8s 原生 CLI（kubectl）。支持容器运维管理、服务治理、应用管理、容器编排，以及多样化扩展插件（集群节点自动扩缩容、历史任务垃圾自动回收等）。

### 3.5.4 优势

| 优势 | 要点 |
| --- | --- |
| 简单易用 | Web 界面一键创建/升级 K8s 集群，支持 VM/物理机混用；一站式自动化部署运维；一键扩缩容；深度集成应用服务网格和 Helm |
| 高性能 | 华为多年技术积累；采用高性能裸金属 NUMA 架构和高速 IB 网卡，AI 计算性能提升 3–5 倍以上 |
| 安全可靠 | 集群控制面支持 **3 Master HA**；节点与工作负载支持跨 AZ 部署；私有集群、整合华为云账号与 K8s RBAC |
| 开放兼容 | 完全兼容 Kubernetes/Docker 社区原生版本，兼容 K8s API 和 kubectl |

### 3.5.5 配置流程

1. **注册华为云账号并登录 CCE 控制台**；
2. **创建集群**：选择计费模式、区域、版本、集群管理规模、控制节点数等参数；后续可通过控制台对工作节点扩缩容（资源不足无法调度时自动触发扩容）；
3. **部署工作负载**：通过镜像或编排模板创建。

**集群升级注意事项**：

- 升级操作**不可回退**，务必慎重并选合适时间段；
- 升级前参考 K8s 版本发布说明，避免应用不兼容；
- 升级中勿关机/重启节点，否则失败；
- 升级前关闭弹性扩缩容策略，避免升级中扩缩容导致失败；
- 本地修改过的节点配置可能导致升级失败或配置丢失，建议通过配置管理和节点池配置管理修改；
- 升级过程中已运行工作负载业务不中断，但 **API Server 访问会短暂中断**。

### 3.5.6 应用场景

- **集群弹性伸缩**：电商促销/秒杀、视频直播、游戏等访问量激增场景，预设策略自动调整容器/云服务器数量；
- **流量治理**：微服务架构下，深度集成应用服务网格，无需改代码即可实现灰度发布、流量治理和监控；
- **DevOps 持续交付**：搭配容器镜像服务，基于代码源自动完成编译、镜像构建、灰度发布、容器化部署；
- **混合云架构**：多云部署/容灾备份、流量分发/弹性伸缩、业务上云/数据库托管、开发与部署分离。

## 考点 / 易错点

- **ECS 规格选择**：电商选**内存优化型**、图形渲染选 **GPU 图形加速型（G1）**、数据分析选**磁盘增强型**、高性能计算选**高性能计算型**、网站选**通用型**。
- **端口记忆**：Windows 远程 **3389**；Linux SSH **22**；VNC 方式**不需要绑定 EIP**，RDP/SSH/远程桌面**需要绑定 EIP**。
- **重装 OS 不影响数据盘**，但会清除系统盘数据；且 **IP、MAC 不变**。
- **BMS 仅支持包周期计费**；创建时**仅能选一个安全组**，之后可关联多个。
- **BMS 网络类型**：高速网络最大 10Gbps；增强高速网络 10GE 及以上；自定义 VLAN 用 QinQ；IB 用 100G Mellanox 网卡、Partition Key 隔离。
- **IMS**：加密镜像不能共享、不能发布到市场；公共镜像支持的操作系统；私有镜像三种子类型（系统盘/数据盘/整机）；导出到 OBS。
- **AS 伸缩带宽仅支持按需带宽**，不支持包年包月；**冷却时间内只拒绝"告警策略"**触发的伸缩活动。
- **CCE**：镜像静态、容器动态；集群升级**不可回退**，升级中 API Server 短暂中断；控制面 3 Master HA。
- **X86 = CISC（复杂指令集）；鲲鹏 = RISC（精简指令集）**。

5. CCE 中 Pod、Node、Cluster 的关系是什么？集群升级有哪些注意事项？

<summary>参考答案</summary>

1. 由 **CPU、内存、操作系统、云硬盘**组成。Windows 默认用户名 `Administrator`（或管理员），Linux 默认用户名 `root`；两者均仅"运行中"的云服务器才允许登录。
2. BMS 兼具虚拟机弹性和物理机性能，是接入云平台的专属物理服务器（自动发放、自动运维、VPC 互联、对接共享存储）；相比物理机，BMS 可在线交付、自动化无人运维、灵活使用；相比 ECS，BMS 无虚拟化损耗、算力 100% 释放、物理机级隔离。核心数据库要求资源专享、网络隔离、性能有保障，不能部署在虚拟机上，故推荐 BMS。
3. 分为公共镜像、私有镜像（含系统盘镜像、数据盘镜像、整机镜像）、共享镜像、市场镜像。加密镜像（KMS 信封加密）不能共享给其他用户、不能发布到应用超市；用加密镜像创建的 ECS 系统盘只能为加密状态且磁盘密钥与镜像密钥一致。
4. 伸缩组=同场景实例集合，是伸缩活动基本单位；伸缩配置=实例模板（规格数据）；伸缩策略=触发伸缩活动的方式（告警/定时/周期）；冷却时间=每次伸缩活动完成后开始计算、用于防止告警策略频繁触发的一段时间。冷却时间内**拒绝由告警策略**触发的伸缩活动，定时策略和周期策略不受限制（但会重新开始计算冷却时间）。
5. Cluster 是容器运行所需的云资源组合（含若干 Node）；Node 对应一台服务器，运行容器应用；Pod 是 K8s 部署的最小基本单位，运行在 Node 上。升级注意事项：不可回退；升级前参考版本发布说明；升级中勿关机/重启节点；升级前关闭弹性扩缩容策略；本地改过配置可能导致失败或丢失；升级中业务不中断但 API Server 访问短暂中断。
6. ×。AS 伸缩带宽仅支持对**按需购买的 EIP 带宽和共享带宽**进行调整，不支持包年包月带宽。
